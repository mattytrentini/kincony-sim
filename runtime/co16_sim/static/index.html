Device online / offline fault stimulus

Offline I²C devices raise real bus errors; restoring them allows normal reads to recover. Each device has its own explicit Apply.

LCD faults are fatal to the original LCD task. An offline SPI write stops drawing. Restoring LCD online does not restart it; restart the simulator process to resume. HTTP remains available.
